# Post-build UI audit 001

Mode: **AFTER**. The working remote was built and exercised before this audit.
No UI change has been made in response to the findings below. Only the owner
can approve specific finding numbers for a follow-up fix.

**Design read:** A bedside remote for a Pi listener using a phone or Kindle
Fire in low light, with a dim, warm, calm visual language. Direction came from
the owner. Dials: **ENERGY 1 / RHYTHM 1 / MOTION 1**.

**Decision reasons:** Dark olive surfaces reduce glare at night; the warm
accent singles out playback and keyboard focus; a bedtime control precedes
the player so leaving bed can silence it; player and folder browser stack on
phones but share the width on a tablet; system fonts work offline and stay
legible; 48 px control heights and spaced rows favor touch; bordered panels
separate urgent, playback, and browsing tasks; text labels replace icons
because their actions should be unambiguous in low light.

## Numbered findings

1. **HIGH, R-25 (human/non-text contrast):**
   `bedside_audio/static/style.css:5-6,189-198,298-307`. Button backgrounds
   differ from their panel by only **1.18:1**, and the shared border is
   **2.06:1** against the panel and **1.76:1** against the button. These
   boundaries miss the 3:1 non-text contrast bar, making controls harder to
   locate for low-vision users. Text and the focus ring do pass.
2. **LOW, R-29/R-31 (palette consistency):**
   `bedside_audio/static/style.css:232-258`. Chromium leaves both range
   inputs at native `appearance: auto`, so their visible thumbs render blue
   instead of the defined warm accent. This adds an unintentional second
   accent and makes the thumb smaller than the intended custom treatment.

### Browser click-through evidence

- Start bedtime enabled playback without auto-starting it; End bedtime stopped playback, canceled the timer, and disabled play.
- Open Show, open Season 1, and Up one folder changed the listing without changing Pi playback; Episode 1 selection began Pi-owned playback.
- Pause/Play changed state; seek to 1:14 reached backend position 74; Next/Previous selected Episode 2/Episode 1.
- Volume set to 30% reached the backend; Set timer showed a decreasing countdown; Cancel timer cleared it. An empty timer field triggered native required-field validation.
- Stop exposed Resume; Resume played again. Reloading the page while playing left the Pi-owned player running.
- A simulated library failure showed Retry files, which restored the listing; a simulated state disconnect showed Retry connection, which restored Connected status.
- At 320 px and 1024 px there was no horizontal overflow; keyboard Tab showed a visible focus ring. The browser console had zero errors after the unnecessary favicon request was avoided.
