# Post-merge UI audit 003

Mode: **AFTER**. This audit covers the configured-playlist and folder-shuffle
UI merged for Bedside Audio 0.7.0. No UI changes were made in response.

**Design read:** A low-light, touch-first bedside remote for a listener using
a phone or tablet. The established direction remains matte, calm, and
task-focused. Dials: **ENERGY 1 / RHYTHM 1 / MOTION 1**.

## Numbered findings

1. **HIGH, R-25 (non-text contrast):**
   `bedside-audio/bedside_audio/static/style.css:5-6,189-200`. The shared
   control border is **2.06:1** against the panel and **1.76:1** against the
   control background. The new playlist and folder action buttons inherit
   those boundaries, below the 3:1 non-text contrast requirement.
2. **LOW, Web Interface Guidelines:**
   `bedside-audio/bedside_audio/static/index.html:14-22`. The page has no skip
   link to `main`.
3. **LOW, Web Interface Guidelines:**
   `bedside-audio/bedside_audio/static/index.html:79`. The timer input has no
   `name` or explicit `autocomplete`.
4. **LOW, Web Interface Guidelines:**
   `bedside-audio/bedside_audio/static/style.css:225-230`. Focus styling uses
   `:focus` instead of `:focus-visible`, so pointer activation retains the
   keyboard focus treatment.

- **R-03 PASS:** The responsive CSS provides single-column, two-action, and
  two-panel states; Node regressions assert 48 px controls and narrow-screen
  reflow.
- **R-25 FAIL:** Finding 1 remains unapproved and affects new controls.
- **R-26 PASS:** Playlist, shuffle, retry, transport, timer, volume, browsing,
  cleanup, and owner controls all have implemented actions.
- **R-27 PASS:** Playlist and library views have loading, empty, error, retry,
  and ready states.
- **R-32 PASS:** Controls use native buttons and inputs; cleanup Escape

- **R-35 PARTIAL:** `node --test tests/*.test.js` passes 25 interaction tests
