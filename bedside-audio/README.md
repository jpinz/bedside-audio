# Bedside audio (Voice)

Bedside Audio is a Home Assistant App for listening to television audio on
wired headphones connected to Home Assistant Voice Preview Edition.

The signed-in Ingress page browses Home Assistant's configured DLNA media
source and controls the Voice media player. The App exposes no host media
port, does not sign in to Plex, and keeps queue, timer, ownership, and
transport policy in the App.

Read [the App documentation](DOCS.md) before installation. Existing local
`local_bedside_audio` installations are separate from this repository App and
do not migrate automatically.
